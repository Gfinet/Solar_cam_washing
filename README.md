# Solar_Cam
This is a personnal project wich will link Solar Panels (MARQUE) with washing machines (MARQUE) and also camera (MARQUE) and ringbell (MARQUE) 

# Installation

## Backend

- fastify `npm install fastify`
- prisma (ORM) `npm install @prisma/client@5 prisma@5`
- bcrypt (hash) `npm install bcrypt`

## Frontend

- React 

## DB

- Postgress

## Proxy

- Nginx
